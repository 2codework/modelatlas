# 独立迁移参考（先作答）
1. 新快照只用guide r3，两块：归档保留45天；主持人努里。没有memo，因此workshop host不再同分，两个查询均为candidate而不是自动回答。原guide r2、memo及private不在输入/当前允许快照。
2. 原30天quote、revision和整文SHA与r3不符，validate_citation=false。空allowlist产生零块，所有查询refused，旧引用无效。不能把旧snapshot继续当作当前证据。
3. storage duration在给定词项规则下0命中。人工控制的同义词表可能提升召回，但会产生多义词误召回；需固定版本、增加无答案/误同义/私有资料/旧版本回归，不允许词扩展改变ACL。向量检索是另一个未来实现，不是本课已具备。
4. quote切片相等证明精确指针；相关性要求回应问题；支持性要求候选主张由可信上下文支持。恶意笔记可被准确引用，但没有执行权。此代码不存在发送工具；更大系统仍需权限/人工闸门，单靠本课不构成注入防御认证。
5. 在自己的运行记录填实际Python版本、命令和输出，不复制作者的运行结果冒充实跑。供应商价格、真实模型质量、账户地区、组织许可均未知。本练习只教本地检索与引用契约。
