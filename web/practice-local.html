第一次本地模型

仅 macOS 14+ · 需要安装与下载 · 先核对设备资源

本页只展示教程和下载文件，不接收密钥、不发模型请求。API / 本地运行不是 MCP；这两条练习不需要 MCP、Skill 或外部办公权限。

这条路适合谁

想看清“模型下载 → 运行时加载 → 给一条输入 → 收到文字”的人。需要额外安装和下载，不是默认入门路径。官方起点：Ollama macOS 下载，安装要求见 macOS 文档 [L1, L2]。本包没有替你执行任何步骤。

适用版本、文档日期与核验范围

范围：2026-10-29 读取的滚动官方文档；macOS Sonoma 14 或更新；Apple M 系列支持 CPU/GPU，x86 Mac 为 CPU only [L2]。这里只讲 macOS，不宣称同一套适合 Linux/Windows。运行时不是固定测试版本：安装前看官方发布信息，安装后在应用 About/版本信息记录实际版本；本包没有安装版本号或实测兼容矩阵。

唯一模型标签：qwen3:0.6b。观察时页面短 ID 7df6b6e09427、Q4_K_M、显示 523MB [L3]；标签可更新，短 ID 不是本包核验过的完整权重哈希。523MB 是下载制品标注，不是最低 RAM 或显存。还需要运行时、缓存和上下文内存；本包不承诺最低内存、速度、耗电或能在你的机器跑通。先查看“关于本机”、储存空间和活动监视器；资源紧张、工作机无安装权限或不接受下载时停止。

1．自己安装官方运行时

  1. 浏览器打开官方起点，选择 macOS 的手动下载入口；看清域名与系统要求。不要复制下载页给 agent 的自动安装指令，也不要运行来历不明的 curl | sh。
  2. 按 macOS 官方说明打开下载的 ollama.dmg，将 Ollama 拖到 Applications，打开应用。若提示把 CLI 链接放到 /usr/local/bin，先看清权限含义，再自行决定 [L2]。
  3. 打开 Terminal。下面命令是运行时的本地模型清单，不是生成请求：
ollama ls

能显示清单或空表才继续。command not found 时重开 Terminal、确认应用安装/CLI 链接；不要为了本练习直接给未知程序管理员权限。不能连接服务时先确认 Ollama 应用已启动；不要再盲开多个服务占用端口。

2．明确下载一个模型

先看模型页和原作者模型卡 [L3, L4]，再在 Terminal 粘贴：

ollama pull qwen3:0.6b
ollama ls

pull 会联网下载权重、占用磁盘；不是我们已经替你下载好了。完成后清单应出现该标签；记录实际 ID/大小。失败时看网络/磁盘错误，停止，不换更大模型重试。不要选择 :cloud 型号，不需要 ollama signin、OpenAI key 或付费云端接口。

许可分开看：Ollama 软件仓库当前 LICENSE 为 MIT [L8]；这个模型标签及 Qwen 原作者卡标注 Apache-2.0 [L3, L4]。这不是我们新授予你的许可证，也不代表所有模型同许可。正式分发/商用前应复核你实际下载版本的完整许可、NOTICE 及相关义务；教程不替你作法律判断。

3．给模型一次完整输入

下载 local_request.sh（仅文件，不自动执行）
查看并复制完整脚本
#!/bin/bash
# Reader-run only, after official Ollama installation and explicit model pull.
# This is local inference, not an OpenAI API call. No credentials.
curl --disable --noproxy '*' --connect-timeout 5 --max-time 120 \
  --silent --show-error --include \
  http://127.0.0.1:11434/api/chat \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen3:0.6b",
    "messages": [{"role":"user","content":"只根据虚构材料输出两行，格式为事项｜负责人｜日期｜依据。缺失值写待确认，不补猜。材料：[L1]小林确认2026-10-30提交海报。[L2]场地报价还没收到，负责人和日期未定。 /no_think"}],
    "stream": false,
    "options": {"num_predict": 160},
    "keep_alive": 0
  }'
curl_status=$?
printf '\ncurl exit=%s；HTTP 状态另看上面的响应头。若超时，按教程停止本地模型。没有自动重试。\n' "$curl_status"
exit "$curl_status"

把 local_request.sh 保存到一个练习文件夹，Terminal cd 到该文件夹，然后运行：

bash local_request.sh

也可以把该文件内容完整粘到 Terminal。脚本把 --disable 放在 curl 第一个选项，避免读取用户 .curlrc 添加额外 URL、代理、重试或重定向（curl 官方手册，L10）。它只向 http://127.0.0.1:11434/api/chat 发一次请求：这是自己电脑的 Ollama，不是 OpenAI，也不是 Ollama 云端。官方 API 说明支持 model、messages、stream:false、options 和 keep_alive [L6]；num_predict 最大生成 token 语义见 [L7]。完整输入和配置如下（实际 shell 文件内容与此一致）：

{
  "model": "qwen3:0.6b",
  "messages": [{"role":"user","content":"只根据虚构材料输出两行，格式为事项｜负责人｜日期｜依据。缺失值写待确认，不补猜。材料：[L1]小林确认2026-10-30提交海报。[L2]场地报价还没收到，负责人和日期未定。 /no_think"}],
  "stream": false,
  "options": {"num_predict": 160},
  "keep_alive": 0
}

/no_think 是原作者描述的提示软开关 [L4]，不当作所有运行时/模板都保证的硬控制。160 token 是生成上限，不保证答案完整；keep_alive:0 请求完成后卸载模型；网络等待最多 120 秒，只是本教程的客户端限制，不是速度承诺。此例不启用工具、不读取文件、不安装 MCP/skill。

Ollama 默认绑定回环地址 [L9]。本练习不更改 OLLAMA_HOST、不开放 11434 端口、不做隧道、不授权其他应用。安装/模型下载需要网络；本例选本地标签、请求回环地址，不把“本地”泛化成所有 Ollama 功能永远离线或不会有日志。

4．怎样才算跑通

屏幕应出现 HTTP 状态和一个 JSON。找 model、message.content、done、done_reason、eval_count 等字段 [L6]；它们是预期响应结构，不是本次测出的值。检查：

  • HTTP 200，返回模型标签符合选择，done:true，message.content 有可读文本。
  • done_reason 不是因为达到上限而截断；若文字不完整，不算内容验收通过。
  • 内容必须保留 L1 的小林和日期，L2 负责人/日期写待确认，不编造承诺。

人工编写的内容参考（非实跑回答）：

提交海报｜小林｜2026-10-30｜L1
跟进场地报价｜待确认｜待确认｜L2

模型能加载/输出不等于会正确做办公任务。小模型若答错，先记错；愿意再试才手动把 messages[0].content 换成下面自包含纠错提示，仍只运行一次：

只根据虚构材料重做两行：事项｜负责人｜日期｜依据。[L1]小林确认2026-10-30提交海报。[L2]场地报价还没收到，负责人和日期未定。检查第二行：负责人和日期必须都写待确认。不要解释或补猜。 /no_think

无须同时照抄官方模型页的 ollama run qwen3:0.6b；那是另一种交互入口，本练习用受限的一次 HTTP 输入，避免不清楚自己正在给哪个会话发消息。

失败、停止和卸载范围

症状安全处理
pull 网络/磁盘失败停止下载，检查资源/官方说明。不更换镜像、不禁用 TLS、不反复下载多个模型。
无法连接 127.0.0.1:11434确认应用运行；不要改成公网地址或云端 API 作为“修复”。
模型不存在 / 404用 ollama ls 核对标签；没下载完成先解决下载问题。
内存不足、明显卡顿、持续高压力停生成，关闭本次模型，不继续扩上下文。不能因为文件只有 523MB 就断言内存足够。
HTTP 错误 / 参数不支持保留状态和脱敏错误，核对实际运行时版本及官方文档；停止，不静默换模型。
120 秒超时不宣称失败请求已自动取消；先停止模型，不并发重试。
空答案、截断、把缺项乱补记录未通过；一次手动纠错仍错就返回网页练习，不把流畅当准确。

中断当前客户端：Terminal 按 Ctrl+C。然后在另一 Terminal 或命令结束后运行 [L5]：

ollama stop qwen3:0.6b
ollama ps

ps 查看是否仍有模型加载；这不删除权重。应用仍可能后台运行，需要时从菜单栏退出 Ollama。若想仅移除本练习模型，先确认没有别的工作依赖它：

ollama rm qwen3:0.6b
ollama ls

rm 会移除该本地模型条目，不是只清一次会话。完全卸载应用请按 macOS 官方卸载说明逐项核对；不要为本练习复制整段递归删除命令。~/.ollama 含其他模型和配置，整目录删除可能丢失个人数据；本包不要求也不执行这种删除。只删除你新建的练习文件夹即可清掉教程文件，别删除系统 Python/curl 或别人的模型。
