# 从字符到 token ID：微型 BPE

原创可运行的 Unicode 字符级 BPE 教学简化，不是厂商分词器、字节级 BPE 或语言模型。前置：列表、字典、循环与整数运算。目标：统计相邻对、学两条规则、冻结分词器、编码解码新词串并说明失败边界。未进行学习者试学或完成时间测量。

## 契约

语料是1..32个不同的非空词串及1..1000的正整数频数。每个词串最多64个Unicode代码点；频数加权总长度最多10000。拒绝空白与代理代码点，不偷偷归一化或删除。词串独立，不跨边界统计；这不是整句预分词器。没有Unicode归一化、特殊token协议、聊天模板或字节回退。

训练按词频加权统计相邻token对。选择最高频对；平局按Python元组的Unicode代码点字符串顺序。每轮重算频数，左至右非重叠合并。初始ID按唯一字符排序；新合并字符串取下一个ID，若同形字符串已存在则复用原ID，不覆盖它。整数预算0..32次，或无相邻对时提前停止。返回不可变元组规则/词表及独立检查trace。

编码按已学顺序使用冻结规则，不从新输入学习。只接受1..256代码点的一个词串，未知字符明确报错。解码拼接词表字符串；要求1..256个严格整数ID，解码后不超过256字符。空输入拒绝。ID只在这份词表有意义，不是跨模型语义编号。任意合法ID序列解码后再编码，不保证恢复原ID分段。这些限制是教学契约，不是所有BPE的通用要求。

## 完整示范语料与推导

W={"abab":2,"abac":1}，字母表a,b,c的ID为0,1,2。

初始相邻对：(a,b)=5、(b,a)=3、(a,c)=1。abab中ab出现两次，每次乘词频2，abac再贡献一次。先合并(a,b)→ab，ID 3。

分段变为abab→[ab,ab]、abac→[ab,a,c]。重新计数：(ab,ab)=2、(ab,a)=1、(a,c)=1。第二次合并(ab,ab)→abab，ID 4。最终词表[a,b,c,ab,abab]。

冻结编码：abab→[4]；abac→[3,0,2]；未在训练中出现的新组合ababc→[4,2]。解码还原原词串。ababc的5个字符变为2个教学token，不能据此估计真实API费用或证明理解。

计数不等于替换次数：aaa中有两个重叠(a,a)，一次左至右合并只得到[aa,a]，不是[aa,aa]。语料{"ac":1,"ab":1}的首轮平局选(a,b)，不依赖字典插入顺序。

## 运行与检查

Python 3.9+，仅标准库。先审阅core.py，再解压ZIP进入bpe-tokenizer：

    python3 -B demo.py
    python3 -B -m unittest -v

无需安装依赖、账号、网络、GPU、权重或API Key。网页不执行Python；demo只在内存计算并打印JSON，不写入分词器文件。核对trace、vocabulary、encoded、roundtrips和frozen_tokenizer_unchanged=true。测试检查算法契约，不是模型性能或学习者掌握率。

在自己的副本把demo中的合并预算改为0、1、2，记录差异；跑测试前还原。分词器训练学习符号规则，不是神经语言模型权重训练。不能把本课ID直接送入不相干的模型。

## 独立迁移

T={"猫猫狗":2,"猫狗":1}，预算2次。先填写WORKSHEET-zh.md，再打开REFERENCE-zh.md：首轮频数、两次规则、带ID词表、冻结编码/解码猫狗猫狗，以及猫鸟会怎样。解释排序为什么不是拼音，为什么新输入不改规则，为什么token少不证明语言能力好。

## 恢复与验收

频数不一致：核对词频，并在合并前统计所有相邻对，勿拼接独立词串。ID不一致：恢复代码点排序与预算。未知字符：保留原输入和错误，不能默默删字。改变语料或归一化策略会产生不同分词器及不兼容ID，不能把它当旧输出的补丁；保留旧版本并重新测试。

验收：不看参考重建示范频数与规则；解释重叠、平局与边界；有理由完成迁移；实际跑demo与测试，记录Python版本、命令及输出；列出至少三项缺失的生产功能。通过不意味着精通、压缩质量保证或真实模型兼容。
