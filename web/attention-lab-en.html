MODELATLAS · MECHANISM LAB / ORIGINAL LESSON

Attention lab: from scores to output

Prerequisites: weighted averages and the token/attention chapter. Goal: verify scaling, softmax and weighted output, then explain how a causal mask changes visible positions.

This demonstrates mathematics only. T1, T2 and T3 are fixed teaching token labels, not real tokenization. Scores are supplied by the author, not learned model parameters. No training, semantic understanding, model benchmark or proof of causal explanation. No API, external calls, downloads or progress storage.

1 · Inspect the inputs

To focus on the later steps, we supply dot-product scores QKᵀ directly; Q/K projections are not computed. Key dimension dₖ = 4, so divide by √4 = 2. V contains three scalars [2, 6, 10] (dᵥ = 1). Rows are query positions; columns are key positions. ln means natural logarithm.

          T1       T2        T3
QKᵀ = [ [  0,    2 ln 2,   2 ln 3 ],
        [  2,       0,       −2    ],
        [  0,       0,        0    ] ]
V = [2, 6, 10]

sⱼ = (qᵢ · kⱼ) / √dₖ
wⱼ = exp(sⱼ − m) / Σₗ∈A exp(sₗ − m), m = maxₗ∈A sₗ
yᵢ = Σⱼ wⱼ Vⱼ

A is the visible set: all positions without masking; j ≤ i, including the query itself, with the causal mask. Hidden positions get weight 0, equivalent to a −∞ score before softmax. Subtracting the largest visible score m preserves weights and prevents exponential overflow; it does not change attention temperature.

3 · Hand-calculate, then check

Known result (T1, no mask): scaled scores are [0, ln 2, ln 3]; unshifted exponentials are [1, 2, 3], summing to 6. Weights are [1/6, 2/6, 3/6], so output = 2/6 + 12/6 + 30/6 = 22/3 ≈ 7.333333. The table uses shifted exponentials [1/3, 2/3, 1]; weights are unchanged.

Prediction (fixed scenario, independent of current controls): what is the output for T1 with the causal mask enabled?

Answer, explanation and next attempt

The output is 2. Only T1 is visible, with weights [1, 0, 0]. Do not softmax over all three and then merely zero future weights: they would no longer sum to 1. Next select T3: equal scores and all three positions visible give weights 1/3 and output 6; enabling the mask changes nothing. If your answer is wrong, inspect visibility, then the normalization denominator, then the weighted sum.

Recovery: blank or invalid answers never enter the calculation. Clear and re-enter; Reset experiment restores T1 / no mask and clears the answer. Language links preserve query, mask and valid numeric answers, but require a fresh answer check; invalid answers are not carried over. Uncomputed results are not shown as success. If scripts fail, reload or continue with the hand calculation.

4 · Explain the limits, continue learning

Checkpoint: explain scaling, why weights sum to 1, and why T1 cannot read future positions. A real Transformer also includes learned projections, multiple heads, positional mechanisms, residual paths and feed-forward layers; none is implemented here. Neither are training loss, gradients or sampling. Weight size does not prove semantics, truth or causality. This small lab is not completion of the whole course.
