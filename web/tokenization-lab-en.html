From characters to token IDs

Original, runnable Unicode-character BPE lesson, not a vendor tokenizer, byte-level BPE or language model. Prerequisites: lists, dictionaries, loops and integer arithmetic. Outcome: count pairs, learn two rules, freeze a tokenizer, encode/decode a new word and explain failure boundaries. No learner trial or completion-time claim.

Language and region are independent. This offline algorithm needs no provider account; navigation preserves a valid selected region only.

Worked trace · Run the source · Independent transfer · Downloads

Contract

A corpus is 1..32 distinct nonempty word strings with positive integer frequencies 1..1000. Each word has at most 64 Unicode code points; the frequency-weighted total is at most 10000. Whitespace and surrogate code points are rejected, not normalized or discarded. Words are independent: no pair crosses a boundary. This is not a sentence pre-tokenizer. There is no Unicode normalization, special-token protocol, chat template or byte fallback.

Training counts adjacent token pairs weighted by word frequency. Choose maximum count; ties use Python tuple ordering of Unicode code-point strings. Recount after every merge. Replace left-to-right without overlap. Initial IDs follow sorted unique characters; each new merged string gets the next ID. If a merged string already exists, reuse its ID, without overwriting it. Stop after the integer budget 0..32 or when no pairs remain. Training returns immutable tuple-based rules/vocabulary plus a separate inspection trace.

Encoding uses frozen rules in their learned order; it does not learn from the new input. One word of 1..256 code points is supported; unknown characters fail explicitly. Decoding joins vocabulary strings; 1..256 exact integer IDs are required and decoded length is capped at 256. Empty input is rejected. IDs are local to this tokenizer, not semantic labels shared by models. A decoded arbitrary valid ID sequence need not be the canonical encoding of that word. These are teaching bounds, not general BPE requirements.

Worked corpus and full trace

W = {"abab":2, "abac":1}. Alphabet a,b,c receives IDs 0,1,2.

Initial pairs: (a,b)=5, (b,a)=3, (a,c)=1. The two occurrences of ab inside abab each count twice because the word frequency is 2; abac contributes one more. Merge(a,b)→ ab, ID 3.

Pieces: abab→[ab,ab], abac→[ab,a,c]. New pairs: (ab,ab)=2, (ab,a)=1, (a,c)=1. Merge(ab,ab)→ abab, ID 4. Vocabulary is [a,b,c,ab,abab].

Frozen encoding: abab→[4]; abac→[3,0,2]; new combination ababc→[4,2]. Decoding reconstructs each exact word. The 5 characters of ababc become 2 toy tokens; neither count estimates a real API bill or proves understanding.

Pair counting and replacement differ: aaa contains two overlapping(a,a) pairs, but one left-to-right merge produces[aa,a], not[aa,aa]. With corpus {"ac":1,"ab":1}, the tied first choice is(a,b), regardless of dictionary insertion order.

core.py
"""Original bounded Unicode-character BPE lesson; not a vendor tokenizer."""
from collections import Counter
from dataclasses import dataclass


def integer(value, low, high):
    if type(value) is not int or not low <= value <= high:
        raise ValueError('integer outside allowed range')


def word(value, maximum=256):
    if type(value) is not str or not 1 <= len(value) <= maximum:
        raise ValueError('one nonempty bounded word string required')
    if any(c.isspace() or 0xD800 <= ord(c) <= 0xDFFF for c in value):
        raise ValueError('whitespace and surrogate code points are unsupported')


def merge_once(symbols, pair):
    """Left-to-right non-overlapping replacement, returning a new tuple."""
    result, i = [], 0
    while i < len(symbols):
        if i + 1 < len(symbols) and (symbols[i], symbols[i+1]) == pair:
            result.append(pair[0] + pair[1]); i += 2
        else:
            result.append(symbols[i]); i += 1
    return tuple(result)


@dataclass(frozen=True)
class Tokenizer:
    alphabet: tuple
    merges: tuple
    vocabulary: tuple


def validate(model):
    if type(model) is not Tokenizer or type(model.alphabet) is not tuple or type(model.merges) is not tuple or type(model.vocabulary) is not tuple:
        raise ValueError('invalid tokenizer')
    if not model.alphabet or any(type(s) is not str or len(s) != 1 for s in model.alphabet):
        raise ValueError('invalid alphabet')
    for s in model.alphabet: word(s)
    if model.alphabet != tuple(sorted(set(model.alphabet))) or len(model.merges) > 32:
        raise ValueError('invalid alphabet order or merge count')
    vocab = list(model.alphabet)
    for pair in model.merges:
        if type(pair) is not tuple or len(pair) != 2 or any(type(s) is not str or s not in vocab for s in pair):
            raise ValueError('merge depends on unavailable symbols')
        token = ''.join(pair)
        if len(token) > 64: raise ValueError('merged symbol too long')
        if token not in vocab: vocab.append(token)
    if tuple(vocab) != model.vocabulary: raise ValueError('invalid vocabulary IDs')


def train(corpus, budget=2):
    integer(budget, 0, 32)
    if type(corpus) is not dict or not 1 <= len(corpus) <= 32:
        raise ValueError('1..32 distinct word strings required')
    for text, frequency in corpus.items():
        word(text, 64); integer(frequency, 1, 1000)
    if sum(len(text)*frequency for text, frequency in corpus.items()) > 10000:
        raise ValueError('weighted corpus exceeds 10000 characters')
    alphabet = tuple(sorted(set(''.join(corpus))))
    vocab, rules, trace = list(alphabet), [], []
    pieces = {text: tuple(text) for text in sorted(corpus)}
    for _ in range(budget):
        counts = Counter()
        for text, symbols in pieces.items():
            for pair in zip(symbols, symbols[1:]): counts[pair] += corpus[text]
        if not counts: break
        pair = min(counts, key=lambda p: (-counts[p], p))
        pieces = {text: merge_once(symbols, pair) for text, symbols in pieces.items()}
        token = ''.join(pair)
        if token not in vocab: vocab.append(token)
        rules.append(pair)
        trace.append({'counts': [(a,b,counts[(a,b)]) for a,b in sorted(counts)],
                      'selected': pair, 'pieces': dict(pieces)})
    model = Tokenizer(alphabet, tuple(rules), tuple(vocab))
    validate(model)
    return model, trace


def encode(model, text):
    validate(model); word(text)
    unknown = sorted(set(text) - set(model.alphabet))
    if unknown: raise ValueError('unknown characters: ' + repr(unknown))
    symbols = tuple(text)
    for pair in model.merges: symbols = merge_once(symbols, pair)
    return tuple(model.vocabulary.index(s) for s in symbols)


def decode(model, ids):
    validate(model)
    if type(ids) not in (tuple, list) or not 1 <= len(ids) <= 256:
        raise ValueError('1..256 token IDs required')
    for i in ids: integer(i, 0, len(model.vocabulary)-1)
    result = ''.join(model.vocabulary[i] for i in ids)
    if len(result) > 256: raise ValueError('decoded word exceeds 256 characters')
    return result

 def test_roundtrip(self):
  import itertools
  for budget in range(3):
   m,_=train(WORKED,budget)

     text=''.join(chars);self.assertEqual(decode(m,encode(m,text)),text)
 def test_unknown_and_whitespace(self):
  m,_=train(WORKED)
  for s in ('','a b','ab\n','x','a\ud800'):
   with self.assertRaises(ValueError):encode(m,s)
 def test_bad_corpus(self):
  for c in ({},{'':1},{'a b':1},{'a':True},{'a':0},{'a':1.5},{'a'*65:1},{'a'*64:1000},[],{'a':1001}):
   with self.assertRaises(ValueError):train(c)
 def test_bad_budget(self):
  for b in (True,-1,33,1.1,'2'):
   with self.assertRaises(ValueError):train(WORKED,b)
 def test_bad_ids(self):
  m,_=train(WORKED)
  for ids in ([],[True],[-1],[5],[0.0],'0',[4]*257):
   with self.assertRaises(ValueError):decode(m,ids)
 def test_bad_model_and_lengths(self):
  m,_=train(WORKED)
  for bad in (None,Tokenizer(('a',),(('a','b'),),('a','ab')),Tokenizer(('a',),(),('x',))):
   with self.assertRaises(ValueError):encode(bad,'a')
  with self.assertRaises(ValueError):encode(m,'a'*257)
  with self.assertRaises(ValueError):decode(m,[4]*65)

# 从字符到 token ID：微型 BPE

原创可运行的 Unicode 字符级 BPE 教学简化，不是厂商分词器、字节级 BPE 或语言模型。前置：列表、字典、循环与整数运算。目标：统计相邻对、学两条规则、冻结分词器、编码解码新词串并说明失败边界。未进行学习者试学或完成时间测量。

## 契约

语料是1..32个不同的非空词串及1..1000的正整数频数。每个词串最多64个Unicode代码点；频数加权总长度最多10000。拒绝空白与代理代码点，不偷偷归一化或删除。词串独立，不跨边界统计；这不是整句预分词器。没有Unicode归一化、特殊token协议、聊天模板或字节回退。

训练按词频加权统计相邻token对。选择最高频对；平局按Python元组的Unicode代码点字符串顺序。每轮重算频数，左至右非重叠合并。初始ID按唯一字符排序；新合并字符串取下一个ID，若同形字符串已存在则复用原ID，不覆盖它。整数预算0..32次，或无相邻对时提前停止。返回不可变元组规则/词表及独立检查trace。

编码按已学顺序使用冻结规则，不从新输入学习。只接受1..256代码点的一个词串，未知字符明确报错。解码拼接词表字符串；要求1..256个严格整数ID，解码后不超过256字符。空输入拒绝。ID只在这份词表有意义，不是跨模型语义编号。任意合法ID序列解码后再编码，不保证恢复原ID分段。这些限制是教学契约，不是所有BPE的通用要求。

## 完整示范语料与推导

W={"abab":2,"abac":1}，字母表a,b,c的ID为0,1,2。

初始相邻对：(a,b)=5、(b,a)=3、(a,c)=1。abab中ab出现两次，每次乘词频2，abac再贡献一次。先合并(a,b)→ab，ID 3。

分段变为abab→[ab,ab]、abac→[ab,a,c]。重新计数：(ab,ab)=2、(ab,a)=1、(a,c)=1。第二次合并(ab,ab)→abab，ID 4。最终词表[a,b,c,ab,abab]。

冻结编码：abab→[4]；abac→[3,0,2]；未在训练中出现的新组合ababc→[4,2]。解码还原原词串。ababc的5个字符变为2个教学token，不能据此估计真实API费用或证明理解。

计数不等于替换次数：aaa中有两个重叠(a,a)，一次左至右合并只得到[aa,a]，不是[aa,aa]。语料{"ac":1,"ab":1}的首轮平局选(a,b)，不依赖字典插入顺序。

## 运行与检查

Python 3.9+，仅标准库。先审阅core.py，再解压ZIP进入bpe-tokenizer：

    python3 -B demo.py
    python3 -B -m unittest -v

无需安装依赖、账号、网络、GPU、权重或API Key。网页不执行Python；demo只在内存计算并打印JSON，不写入分词器文件。核对trace、vocabulary、encoded、roundtrips和frozen_tokenizer_unchanged=true。测试检查算法契约，不是模型性能或学习者掌握率。

在自己的副本把demo中的合并预算改为0、1、2，记录差异；跑测试前还原。分词器训练学习符号规则，不是神经语言模型权重训练。不能把本课ID直接送入不相干的模型。

## 独立迁移

T={"猫猫狗":2,"猫狗":1}，预算2次。先填写WORKSHEET-zh.md，再打开REFERENCE-zh.md：首轮频数、两次规则、带ID词表、冻结编码/解码猫狗猫狗，以及猫鸟会怎样。解释排序为什么不是拼音，为什么新输入不改规则，为什么token少不证明语言能力好。

## 恢复与验收

频数不一致：核对词频，并在合并前统计所有相邻对，勿拼接独立词串。ID不一致：恢复代码点排序与预算。未知字符：保留原输入和错误，不能默默删字。改变语料或归一化策略会产生不同分词器及不兼容ID，不能把它当旧输出的补丁；保留旧版本并重新测试。

验收：不看参考重建示范频数与规则；解释重叠、平局与边界；有理由完成迁移；实际跑demo与测试，记录Python版本、命令及输出；列出至少三项缺失的生产功能。通过不意味着精通、压缩质量保证或真实模型兼容。

第二轮只有(猫,猫狗)=2，合并成猫猫狗，ID 3。

# Transfer reference — use after an independent attempt
Base IDs: 狗=0 (U+72D7), 猫=1 (U+732B), code-point order, not pronunciation.
First counts: (猫,猫)=2; (猫,狗)=3. Select (猫,狗), token 猫狗 ID 2.
Pieces: 猫猫狗→[猫,猫狗] with frequency 2; 猫狗→[猫狗] with frequency 1.
Second count: (猫,猫狗)=2. Select it; 猫猫狗 becomes ID 3.
Vocabulary: [狗,猫,猫狗,猫猫狗]. Frozen 猫狗猫狗→[2,2] and back to the same word; 猫猫狗→[3]. 猫鸟 fails because 鸟 was absent from the base alphabet. Do not remove it or claim reversible unknown replacement.
Encoding uses existing rules and does not add tokens. A new corpus/rule budget can change IDs and token boundaries. aaa has 2 overlapping pairs but only 1 non-overlapping replacement in one scan. This algorithm learns symbols, not neural weights; no byte fallback, pre-tokenization, normalization, special tokens or chat templates. Its token count says nothing about a vendor's bill or model understanding.
