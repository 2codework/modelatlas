# 九个参数：真正更新一次

需要 Python 3.9+，只用标准库。不安装依赖，不用账号、API Key、GPU、网络或预训练模型。解压 tiny-training-lab.zip，进入 tiny-training 目录：

```sh
python3 -B demo.py
python3 -B -m unittest -v
```

-B 禁止写入字节码文件；演示只在内存计算并打印 JSON，不保存权重。执行前可读 core.py、fixtures.py、test_core.py。网站不提供执行任意用户代码的服务。这是真实数值更新的 3×3 教学分数表，不是 Transformer、大模型复现、厂商评测或学习效果证明。

## 输入与停止契约
词表仅 A/B/C；行是前一 token，列是下一 token，只看最后一个 token。全批量平均交叉熵使用自然对数。独立序列不拼接；空/单 token 序列不产生样本，整个训练集至少要一个转移。未知或布尔 token、非有限数、错误维度、负学习率、非法生成预算均报 ValueError。极大有限值相减溢出也明确拒绝。所有输入不变；更新返回新表；学习率零不改变值。生成用贪心选择，同分按 A/B/C 顺序，整数预算 0..32，没有 EOS，不保证连贯语言。

## 复现
原始 TRAIN=A B A B A C 有 5 个转移。全零表，学习率 0.3。平均损失应从 1.0986122886681098 降到 1.0439803399807872；更新后行 [-.06,.06,0]、[.08,-.04,-.04]、[0,0,0]。浮点接近零的小残差正常。刻意挑选的、无代表性的 A→A 反例从未参与优化，其损失上升到 1.159811928855196；不能称为代表性泛化测试。失败时恢复原始数据和全零表，不改答案掩盖失败。大学习率不保证损失下降。
