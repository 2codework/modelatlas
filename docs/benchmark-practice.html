目标与边界

交付一份评测阅读账本、C1–C3三个修订结论、至少两项未知，以及两条独立迁移比较决定与人工自查。原三题编辑估计15–20分钟；新增迁移另计，只用本页材料完成；不是实测用时。外部原文延伸阅读另计。

只需纸笔或本地文本编辑器。无需账号、安装、密钥、模型下载或付费。页面不保存填写内容，也不自动判分；本页无需JavaScript。

本课只读来源，不执行评测。

本站未运行这些基准，也没有独立复现。网页与自动测试通过只说明页面检查结果，不说明模型性能。本课不要求跟随原文的下载、安装或API步骤。

基准
用一套任务和评分办法观察能力；不是所有真实工作的总成绩。
harness
组织输入、调用模型和计分的评测程序；版本与设置可能影响结果。
判分模型
评判输出的另一个模型，也叫judge；它的版本是评测条件之一。
CoT
思考或推理模式相关的提示与流程；不能默认不同模式使用同样条件。
独立复现
另一方实际执行并留下可检查的过程与结果；读过官方报告不算。

3．修正三个结论

以下是人工编写的待核主张，不是模型实际输出。先写“支持 / 不支持 / 证据不足”及理由，再展开答案；判断标签可讨论，但证据范围不能扩大。

C1 · “官方修正并公开了代码，所以本站已独立实测证实结果。”

做完再看：C1参考答案

不支持。A证明发布者公告过更正与代码公开，不证明本站执行过任何评测。修订：发布者于2025-06-15公告更正；本站于2026-10-31阅读该公告，未独立复现。

C2 · “RISE说明段默认是2.0，因此普通Results的实验一定使用2.0，标题1.5肯定写错了。”

做完再看：C2参考答案

证据不足。B有不同范围的标注。不能把当前默认值当成某张表的运行记录，也不能反过来确定1.5就是所有实验的设置。修订：分别记录默认2.0与结果标题1.5；实际配置及映射待核，需对应版本、配置和运行记录。不能据此认定文档错误或推导性能差异。

C3 · “只要同名基准分数更高，就证明模型在相同条件下更强。”

做完再看：C3参考答案

证据不足。本页没有提供可作这一结论的完整对照实验。至少需核对模型快照、数据版本/子集、harness、提示词/模式、judge、生成配置、预算及指标口径。修订：条件未核齐，暂不直接比较；即使条件一致，也只说明该评测范围，不自动推广到所有工作。

参考答案是编辑推理，不是新实验或官方结论。公告更正也不意味着所有其他结果都不可信；未知既不是零分，也不是反面结论已成立。

4．独立迁移：同名任务，是否同一条件？

先离开上面的 BAGEL 答案。以下是原创虚构记录卡，没有真实厂商、运行日志或成绩；编号和版本仅用于纸面练习。不要把它们录入模型目录。

T-A

教学模型 Cedar-r1；教学数据 LedgerQA-v1 / Full（100题）；程序 harness-h1；提示 p1；一次输出；精确匹配准确率；同一虚构运行环境 e1。以上是题设字段，不是运行证据。

T-B

与 T-A 其他题设字段相同，但子集为 LedgerQA-v1 / Hard（20题）。没有任何成绩或原始输出。

T-C

数据为 LedgerQA-v1 / Full（100题），提示、输出次数、指标与环境同 T-A；模型仅写滚动别名 Cedar-latest，具体快照未知；程序版本未知。没有任何成绩或原始输出。

独立写两条比较决定：T-A 与 T-B 是否能直接作同条件模型排名？T-A 与 T-C 是否已确认条件相同？每条都写：判断、卡片字段证据、缺什么、未补齐前的处理。再写两句不排名的结论。题设相同也不证明真实实验执行。

做完再看：T-A / T-B 参考

不能直接作同条件模型排名。明确差异是 Full / Hard 子集及100 / 20题，不应把两者合并成同一测试；两卡模型甚至相同。先固定同一数据修订与子集、题目范围和计分聚合，再索取对应输出与运行记录。现有卡片只支持识别条件差异，没有性能结论。

做完再看：T-A / T-C 参考

条件是否相同仍未知。Full 相同不足以弥补 Cedar-latest 未固定快照和 harness 版本缺失。需要别名在该次运行时对应的模型修订、程序提交与配置及输出记录，不能照抄 T-A 的版本补空。当前停止直接比较，不能推断 C 更强、较弱或等同。

做完再下载参考与迁移自查

迁移验收：两条决定各有具体字段依据；区分“已知不同”和“未知是否相同”；各列至少一项缺失证据和暂缓动作；没有虚构分数、假装独立复现或把题设当日志。四项全满足才完成本练习的人工自查，不代表掌握认证。

5．验收与停止

还需交付 T-A/T-B 与 T-A/T-C 两条独立比较决定，并完成迁移四项人工自查。

  • A、B均有来源身份与章节定位；公告日、本站读取日和你的实际阅读日分开。
  • 默认设置与结果标注分开；未固定版本及至少两项未知未被补猜。
  • 三个修订都没有把“官方报告”升级成“独立实测”，也没有生成排名。
  • 最终80—150字结论说明目前能证明什么、不能证明什么、需要什么证据；由人逐项复核。

停止条件：账本、C1–C3三题、有边界的结论、两条迁移比较决定及迁移四项人工自查齐全后即可结束。原文打不开、版本关系不明或缺少运行记录时停在待核，不绕过访问限制、不下载模型、不填密钥，也不为完成练习强求实验结果。

用于真实选型时，先另行确认任务、预算、权限与可复现方案。本课仅训练阅读判断，不是模型选型结论。
