做完得到什么

把 两行虚构会议材料变成带依据的两行行动表。先学“发送一次、读状态、验内容、停下来”；不是搭建自动代理。官方起点：OpenAI API Quickstart [A1]。

适用版本、文档日期与核验范围

范围：2026-10-29 官方滚动文档；OpenAI Responses HTTP API POST https://api.openai.com/v1/responses；固定 gpt-5.4-mini-2026-03-17。该快照及 reasoning.effort=none 有官方模型页依据 [A3]。不是“当前最佳”推荐，也不保证你的项目已有访问权限。macOS/Linux 的 Bash + 已安装 Python 3（示例语法要求 3.8+）；Windows 不直接复制这些终端命令。无 Python 时先回到网页练习，本包不替你安装。

先看费用与权限，再动手

  1. 浏览器打开官方起点，自己登录 API 平台、选自己的项目，检查该模型访问及 API 计费/可用额度。ChatGPT 订阅与 API 分开计费；合资格订阅可能有 API 促销额度，但不等于订阅包含无限 API，也不保证你的账户有额度 [A4]。不想接受额外费用就不要继续。
  2. 在官方平台的 API Keys 页面创建个人项目密钥；只给所需请求权限，条件允许时设置到期。不要把密钥发给助理、贴进网页前端、截图、文档、Git、脚本或 shell 配置文件 [A1, A5]。
  3. 本例只有短输入、160 个最大输出 token、无搜索/存储工具/循环。上限约束输出 token，不是美元硬上限。价格以执行时模型价格页为准；运行后对照 usage 和平台用量。账户预算提示不应被你未经核实当成硬停机。不要开自动充值来完成练习。
  4. 输入会传到 OpenAI。store:false 关闭本例响应状态存储，不等于所有服务日志零留存 [A6]。因此只用下面的虚构材料。

1．准备文件（粘到哪里）

下载 first_request.py（仅文件，不自动执行）
查看并复制完整脚本
"""Reader-run only. No SDK. One documented HTTPS request; never auto-retries."""
import json
import os
import sys
import urllib.error
import urllib.request

URL = 'https://api.openai.com/v1/responses'
PAYLOAD = {
    'model': 'gpt-5.4-mini-2026-03-17',
    'reasoning': {'effort': 'none'},
    'input': '只根据虚构材料输出两行，格式为“事项｜负责人｜日期｜依据”。缺失值写“待确认”，不补猜。材料：[L1]小林确认2026-10-30提交海报。[L2]场地报价还没收到，负责人和日期未定。',
    'max_output_tokens': 160,
    'store': False,
}


def text_parts(response):
    """Do not assume the first output item is a text message."""
    if not isinstance(response, dict):
        return []
    output = response.get('output')
    if not isinstance(output, list):
        return []
    parts = []
    for item in output:
        if not isinstance(item, dict) or item.get('type') != 'message':
            continue
        content = item.get('content')
        if not isinstance(content, list):
            continue
        for part in content:
            if (isinstance(part, dict) and part.get('type') == 'output_text'
                    and isinstance(part.get('text'), str)):
                parts.append(part['text'])
    return parts


class NoRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, req, fp, code, msg, headers, newurl):
        return None  # Never forward credentials to a redirected destination.


def main():
    if sys.argv[1:] != ['--send-once']:
        print('未发送。读完费用/隐私说明后，才可加 --send-once。')
        return 2
    key = os.environ.get('OPENAI_API_KEY', '').strip()
    if not key:
        print('未发送：当前终端未设置 OPENAI_API_KEY。不要把密钥写入此文件。')
        return 2
    request = urllib.request.Request(
        URL, data=json.dumps(PAYLOAD, ensure_ascii=False).encode('utf-8'),
        headers={'Content-Type': 'application/json', 'Authorization': 'Bearer ' + key},
        method='POST')
    # No proxy auto-discovery in this teaching script. Do not bypass workplace policy.
    opener = urllib.request.build_opener(urllib.request.ProxyHandler({}), NoRedirect())
    try:
        with opener.open(request, timeout=60) as result:
            response = json.load(result)
            print('HTTP', result.status)
            print('request_id:', result.headers.get('x-request-id', '未返回'))
    except urllib.error.HTTPError as error:
        print('HTTP', error.code, 'request_id:', error.headers.get('x-request-id', '未返回'))
        print('Retry-After:', error.headers.get('Retry-After', '未返回'))
        # Error messages can echo credentials. Redact the exact supplied key before display.
        print(error.read(8192).decode('utf-8', errors='replace').replace(key, '[REDACTED]'))
        print('已停止，没有自动重试。按教程检查 error.code。')
        return 1
    except (urllib.error.URLError, TimeoutError, OSError):
        print('网络/TLS/超时错误。结果未知；不要立刻重发。检查用量后再决定。')
        return 1
    except (ValueError, TypeError):
        print('响应不是预期 JSON。已停止；不自动重试。')
        return 1
    if not isinstance(response, dict):
        print('响应不是预期 JSON 对象。已停止；不自动重试。')
        return 1
    print('status:', response.get('status'))
    print('incomplete_details:', response.get('incomplete_details'))
    print('usage:', json.dumps(response.get('usage'), ensure_ascii=False))
    parts = text_parts(response)
    print('TEXT:\n' + '\n'.join(parts))
    if response.get('status') != 'completed' or not parts:
        print('尚未通过：未完成或没有文本。不要把 HTTP 200 当作练习成功。')
        return 1
    print('传输完成；仍需人工逐行核对内容。没有继续发送。')
    return 0


if __name__ == '__main__':
    raise SystemExit(main())

在本机建一个空文件夹，把包里的 first_request.py 放进去；也可用纯文本编辑器完整复制该文件，保存为同名 .py，不要保存成富文本。在 Terminal 中 cd 到这个文件夹（可输入 cd 后拖入文件夹，再回车）。运行：

bash
python3 --version

若命令不存在就停。脚本使用 Python 标准库组装官方 HTTP 请求，不依赖 OpenAI SDK，因此不存在“已测 SDK 某版本兼容”的声明。脚本阻止重定向、禁用代理自动发现；单位网络要求代理时请找管理员按其规则配置，不绕过规则。

2．只在当前终端设置密钥

先关闭屏幕共享/录屏。以下三行粘到刚才的 Bash，执行后在不回显的提示处粘自己的密钥，回车。密钥不写进代码和命令历史；不要改成把真实密钥写在命令字面量里。环境变量仍可被本机同权限程序读取，不是保险箱。

read -r -s -p '仅在本机输入 API key: ' OPENAI_API_KEY
printf '\n'
export OPENAI_API_KEY

3．明确发送一次

先打开文件看 URL 和 PAYLOAD。完整实际请求体如下；没有隐藏材料、MCP 或 tool 配置：

{
  "model": "gpt-5.4-mini-2026-03-17",
  "reasoning": {"effort": "none"},
  "input": "只根据虚构材料输出两行，格式为“事项｜负责人｜日期｜依据”。缺失值写“待确认”，不补猜。材料：[L1]小林确认2026-10-30提交海报。[L2]场地报价还没收到，负责人和日期未定。",
  "max_output_tokens": 160,
  "store": false
}

HTTP 请求采用 Content-Type: application/json、Authorization: Bearer（值从当前环境变量读取）。端点、输入/输出结构来自文本指南 [A2]；输出上限及未完成状态来自推理指南 [A7]。这是按官方文档组合的原创示例，不是官方保证可在任何账户运行的测试记录。

确认费用与数据边界后，在同一终端输入：

python3 first_request.py --send-once

不带 --send-once 只显示未发送提示。带参数才真正发起一次收费可能的请求；脚本不自动重试。60 秒网络超时不是服务端取消/退款保证。

4．看结构，再核对答案

实际运行时应看到 HTTP 状态、request_id（若服务返回）、status、incomplete_details、usage，然后 TEXT。这些是应检查的字段，不是本次实测值。 正常完成需 status=completed，并从 output 中筛选 type=message，再读取 content 内 type=output_text 的 text。不能假定 output[0].content[0] 一定是文本；SDK 的便利字段 output_text 也不应硬套到原始 HTTP JSON [A2]。

人工编写的内容参考，不是模型实跑回答：

提交海报｜小林｜2026-10-30｜L1
跟进场地报价｜待确认｜待确认｜L2

验收：两行；L1 人名/日期准确；L2 不编人名和日期；没有新任务、预算或外部操作。措辞可不同，但证据和缺项必须对。HTTP 200 只能说明收到响应，不证明内容正确；incomplete、拒答、无文本均不能算通过。

若内容错了：先在本地记下错误，不马上再收费请求。决定再试且已复核费用时，手动将 input 改为下面自包含纠错提示词，仍只发一次（本例不保留会话上下文）：

只根据虚构材料重做两行行动表：事项｜负责人｜日期｜依据。[L1]小林确认2026-10-30提交海报。[L2]场地报价还没收到，负责人和日期未定。请检查 L2，负责人和日期都必须写待确认，不能猜。不要增加其他内容。

失败时怎么收手 [A8]

观察到下一步，不自动执行
401核对密钥所属项目、是否过期/撤销、权限、组织/IP 限制。不要把密钥或完整敏感日志贴出来；重新设置本机环境变量。泄漏就去官方平台撤销。
429先读 error.code：限速才参考 Retry-After 后考虑一次手动重试；余额、项目/组织花费上限或配额不足就停。不要把“加钱/提限”当必做修复。
400 / 404 / 403核对请求字段、快照是否仍可用、项目权限和支持地区。不随机换更贵模型，不绕地区/组织限制。
500 / 503停下查服务状态；需要时遵守 Retry-After，之后手动决定是否再发。
网络/TLS/超时结果可能未知，先看平台用量，不立即重复发送；不要关闭证书验证。
incomplete / 无文本160 token 可能不够，也可能其他原因；读 incomplete_details。不要无脑扩大上限，本练习可到此结束。

停止、清理与成功记录

终端 Ctrl+C 可中断客户端，但不保证已开始的远端请求停止或免计费。结束后：

unset OPENAI_API_KEY
exit

在官方平台复核用量；不再用的这次练习密钥可自行撤销。取消 ChatGPT 订阅不是停止 API 的方法。删除本地练习脚本不撤销远端密钥，也不删除远端记录。脚本无第三方 SDK，因此没有 SDK 卸载步骤；无需删除其他 Python、用户目录或账户数据。

只记录：日期、模型快照、HTTP/status、input/output token 用量、四项内容检查是否通过。不要记录密钥。本包未执行该请求，读者执行前这些结果均未知。
