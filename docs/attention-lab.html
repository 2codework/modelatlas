Attention 实验台：从分数到输出

前置：会做加权平均，读过 token 与 attention 章。目标：亲手核对缩放、softmax 和加权输出，并解释因果遮罩如何改变可见位置。

这里只演示数学。T1、T2、T3 是固定教学 token 标签，不是真实分词；分数由作者指定，不是模型学到的参数。没有训练、语义理解、模型实测或因果解释证明。无 API、外部调用、下载或学习记录存储。

1 · 先明确输入

为聚焦后半段计算，我们直接给定点积分数 QKᵀ，不计算 Q/K 投影。键维度 dₖ = 4，故除以 √4 = 2。V 是三个标量 [2, 6, 10]（dᵥ = 1）。行对应查询位置，列对应键位置。ln 表示自然对数。

          T1       T2        T3
QKᵀ = [ [  0,    2 ln 2,   2 ln 3 ],
        [  2,       0,       −2    ],
        [  0,       0,        0    ] ]
V = [2, 6, 10]

sⱼ = (qᵢ · kⱼ) / √dₖ
wⱼ = exp(sⱼ − m) / Σₗ∈A exp(sₗ − m), m = maxₗ∈A sₗ
yᵢ = Σⱼ wⱼ Vⱼ

A 是可见位置集合：无遮罩时全部可见；因果遮罩只允许 j ≤ i（包括自己）。不可见位置权重为 0，相当于在 softmax 前将其分数设为 −∞。先减去可见分数最大值 m，不改变权重，可避免指数上溢；不是改变 attention 的温度。

3 · 先手算，再自检

已知结果（T1，无遮罩）：缩放分数为 [0, ln 2, ln 3]；未平移的指数为 [1, 2, 3]，总和为 6。因此权重为 [1/6, 2/6, 3/6]，输出 = 2/6 + 12/6 + 30/6 = 22/3 ≈ 7.333333。表中使用减最大值后的指数 [1/3, 2/3, 1]，权重不变。

预测题（固定场景，与当前控件选择无关）：T1 开启因果遮罩后，输出是多少？

解答、解释与下一次尝试

输出是 2。只剩 T1 可见，权重是 [1, 0, 0]。不能先对三个位置做 softmax 再直接把未来权重置零，否则权重和不再为 1。下一次选择 T3：分数相同，三个位置都可见，权重都是 1/3，输出为 6；开启遮罩结果不变。若答案不对，先检查可见集合，再检查归一化分母，最后重算加权和。

恢复：空白或非法答案不会进入计算。清空重填即可；“重置实验”恢复 T1 / 无遮罩并清除答案。语言切换通过链接保留查询位置、遮罩和合法数值答案，但须重新核对；非法答案不传递。未计算结果不显示为成功，脚本失败可重载页面或继续阅读手算。

4 · 解释边界，继续学习

完成检查点：用自己的话解释缩放、为何权重和为 1、为什么 T1 不能读取未来。真实 Transformer 还含学习到的投影、多头、位置机制、残差和前馈层；这里没有实现它们，也没有训练损失、梯度或采样循环。权重大小不能证明语义、答案真实性或因果关系。这个小实验不是完整课程验收。
