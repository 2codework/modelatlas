01 · 先看目标，不急着跑

前置：会读列表、循环、加减乘除与概率。认识自然对数即可，不要求微积分基础。完成后应能从样本手算梯度，解释一个参数如何变化，并分清训练和冻结参数推理。零基础可先回第 01、02 章。本课没有经过试学计时。

这是 9 个可学习分数的 bigram 模型：W[前一 token][下一 token]，行列均按 A、B、C，窗口只有一个 token。不是 attention、Transformer、预训练大模型或厂商实测。它确实执行数值训练，但只学习这张小表。

02 · 五个转移，完整算一次

原创序列 A B A B A C 形成 A→B, B→A, A→B, B→A, A→C。不是六个样本；多个独立序列之间不得拼接成伪样本。起点 W 全零，学习率 η=0.3，全批量平均损失，自然对数。

对输入 a，取该行分数 z=W[a]，先减 m=max(z)，再算 p[j]=exp(z[j]-m)/Σexp(z[k]-m)。这保持分布不变，避免直接 exp 大正数溢出。初始每项概率 1/3。

单样本目标 b 的交叉熵是 ℓ=-ln p[b]；代码用 ln Σexp(z-m) - (z[b]-m)，避免概率下溢后 log(0)。L 是五个 ℓ 的平均，初始 ln 3 = 1.0986122886681098。

本例导数 ∂ℓ/∂z[j] = p[j] - 1[j=b]：先增加各候选的概率，再对正确目标减 1。A→B 的行贡献是 [1/3,-2/3,1/3]（出现两次）；A→C 是 [1/3,1/3,-2/3]（一次）；B→A 是 [-2/3,1/3,1/3]（两次）。每项累加后除以 全部 5 个样本，不是按每行样本数除。

平均梯度 G（行/列 A,B,C）
A: [ 1/5, -1/5,     0 ]
B: [-4/15, 2/15, 2/15 ]
C: [    0,    0,     0 ]

W_new = W_old - 0.3 × G
A: [-0.06,  0.06,  0.00]
B: [ 0.08, -0.04, -0.04]
C: [ 0.00,  0.00,  0.00]

以一个真实参数为例：W[A,B]=0−0.3×(−1/5)=0.06。A→B 目标越常见，该分数这一步越被提高。C 从未作为输入，因此 C 行梯度为零；这不表示 C 不在词表中。

更新后 p(next|A) = [0.3135451441, 0.3535211628, 0.3329336930]
更新后 p(next|B) = [0.3605109470, 0.3197445265, 0.3197445265]
L = (-2 ln p(B|A) -2 ln p(A|B) -ln p(C|A))/5
  = 1.0439803399807872

训练损失下降。但专门选择未参与优化的 A→A 反例，损失从 ln3 升至 1.159811928855196。它刻意无代表性，只反驳“训练改善则处处改善”，不是代表性测试集、泛化评测或模型排行榜。

04 · 冻结参数，再生成

更新完保存 W 的副本，然后 predict 或 generate：参数必须逐项相等。predict 只读取最后一个 token，所以主例表下 A B 与 C B 的下一步分布一样。生成采用贪心策略；同分按 A/B/C 顺序选，固定最多 0..32 个新 token，A 起始生成 8 个得到 ABABABABA。没有 EOS，达到预算停止不表示内容完整。

所有输入闭合在 A/B/C；布尔/未知 token、NaN/Inf、非 3×3 表、负学习率、非整数或越界生成预算都拒绝。过大有限值导致差值溢出也拒绝。学习率 0 返回同值新表。空或单 token 序列没有转移；整个训练至少要一个。没有任意数据批量上限，使用提供的小固定数据；生成预算只限制新 token 数。

core.py
"""Original nine-logit bigram teaching model. Python 3.9+, standard library only."""
import math

VOCAB = ('A', 'B', 'C')
MAX_NEW_TOKENS = 32


def number(value):
    if type(value) not in (int, float):
        raise ValueError('Expected a finite number, not a bool')
    try:
        value = float(value)
    except (OverflowError, ValueError):
        raise ValueError('Number outside finite float range') from None
    if not math.isfinite(value):
        raise ValueError('Expected finite number')
    return value


def vector(values):
    if not isinstance(values, (list, tuple)) or len(values) != 3:
        raise ValueError('Expected three logits')
    return [number(v) for v in values]


def weights(w):
    if not isinstance(w, (list, tuple)) or len(w) != 3:
        raise ValueError('Expected a 3 by 3 table')
    return [vector(row) for row in w]


def zeros():
    return [[0.0] * 3 for _ in VOCAB]


def tokens(sequence):
    if not isinstance(sequence, (list, tuple)):
        raise ValueError('Sequence must be a list/tuple of A/B/C strings')
    if any(type(t) is not str or t not in VOCAB for t in sequence):
        raise ValueError('Closed vocabulary: A, B, C only')
    return list(sequence)


def pairs(sequences):
    if not isinstance(sequences, (list, tuple)):
        raise ValueError('Expected a list/tuple of independent sequences')
    result = []
    for sequence in sequences:
        seq = tokens(sequence)
        result.extend((VOCAB.index(a), VOCAB.index(b)) for a, b in zip(seq, seq[1:]))
    if not result:
        raise ValueError('Training requires at least one within-sequence transition')
    return result


def shifted(row):
    row = vector(row)
    maximum = max(row)
    values = [x - maximum for x in row]
    # Finite inputs may still exceed representable differences: reject explicitly.
    if not all(math.isfinite(x) for x in values):
        raise ValueError('Logit differences exceed finite arithmetic range')
    return values


def softmax(row):
    values = shifted(row)
    exp = [math.exp(x) for x in values]
    denominator = math.fsum(exp)
    return [x / denominator for x in exp]


def loss(w, sequences):
    w = weights(w)
    samples = pairs(sequences)
    losses = []
    for a, b in samples:
        row = shifted(w[a])
        # Do not take log(softmax): probabilities can underflow to zero.
        losses.append(math.log(math.fsum(math.exp(x) for x in row)) - row[b])
    # Divide before summing to avoid avoidable overflow in the sum.
    result = math.fsum(x / len(samples) for x in losses)
    return number(result)


def gradient(w, sequences):
    w = weights(w)
    samples = pairs(sequences)
    grad = zeros()
    for a, b in samples:
        p = softmax(w[a])
        for j in range(3):
            grad[a][j] += (p[j] - int(j == b)) / len(samples)
    return grad


def step(w, sequences, learning_rate=0.3):
    old = weights(w)
    rate = number(learning_rate)
    if rate < 0:
        raise ValueError('Learning rate must be nonnegative')
    grad = gradient(old, sequences)
    return weights([[old[i][j] - rate * grad[i][j] for j in range(3)] for i in range(3)])


def predict(w, context):
    table = weights(w)
    seq = tokens(context)
    if not seq:
        raise ValueError('Prediction requires context')
    return softmax(table[VOCAB.index(seq[-1])])


def generate(w, context, max_new_tokens=8):
    table = weights(w)
    result = tokens(context)
    if not result:
        raise ValueError('Generation requires context')
    if type(max_new_tokens) is not int or not 0 <= max_new_tokens <= MAX_NEW_TOKENS:
        raise ValueError('Generation budget must be integer 0..32')
    for _ in range(max_new_tokens):
        p = predict(table, result)
        # Greedy; ties use fixed A,B,C order. No EOS token in this tiny vocabulary.
        result.append(VOCAB[max(range(3), key=lambda j: p[j])])
    return result

demo.py
"""Run: python3 -B demo.py. Prints only; no network or model downloads."""
import json
from core import zeros, gradient, step, loss, predict, generate
from fixtures import TRAIN, COUNTEREXAMPLE


def main():
    before = zeros()
    after = step(before, TRAIN, 0.3)
    frozen = [row[:] for row in after]
    output = {'parameters': 9, 'samples': 5, 'before': before,
              'gradient': gradient(before, TRAIN), 'after': after,
              'train_loss_before': loss(before, TRAIN),
              'train_loss_after': loss(after, TRAIN),
              'counterexample_loss_before': loss(before, COUNTEREXAMPLE),
              'counterexample_loss_after': loss(after, COUNTEREXAMPLE),
              'p_after_A': predict(after, ['A']), 'p_after_B': predict(after, ['B']),
              'greedy_A_8': generate(after, ['A'], 8)}
    assert after == frozen
    output['inference_parameters_unchanged'] = after == frozen
    print(json.dumps(output, indent=2, allow_nan=False))


if __name__ == '__main__':
    main()
test_core.py
import copy
import math
import unittest
from core import *
from fixtures import TRAIN, TRANSFER, COUNTEREXAMPLE

class TrainingTests(unittest.TestCase):
    def assertTable(self, actual, expected):
        for row, wanted in zip(actual, expected):
            for x, y in zip(row, wanted): self.assertAlmostEqual(x, y, places=10)

    def test_worked(self):
        self.assertEqual(len(pairs(TRAIN)), 5)
        self.assertAlmostEqual(loss(zeros(), TRAIN), math.log(3))
        self.assertTable(gradient(zeros(), TRAIN), [[.2,-.2,0],[-4/15,2/15,2/15],[0,0,0]])
        w=step(zeros(), TRAIN)
        self.assertTable(w, [[-.06,.06,0],[.08,-.04,-.04],[0,0,0]])
        self.assertAlmostEqual(loss(w, TRAIN), 1.0439803399807872)
        self.assertAlmostEqual(loss(w, COUNTEREXAMPLE), 1.159811928855196)
        self.assertGreater(loss(w, COUNTEREXAMPLE),loss(zeros(),COUNTEREXAMPLE))

    def test_transfer(self):
        self.assertTable(step(zeros(),TRANSFER), [[-.06,0,.06],[0,0,0],[.08,-.04,-.04]])

    def test_finite_difference_all_nine(self):
        w=[[.2,-.4,.7],[.3,.1,-.8],[-.1,.5,.9]]
        g=gradient(w, TRAIN)
        for i in range(3):
            for j in range(3):
                a=copy.deepcopy(w); b=copy.deepcopy(w)
                a[i][j]+=1e-6; b[i][j]-=1e-6
                self.assertAlmostEqual(g[i][j],(loss(a,TRAIN)-loss(b,TRAIN))/2e-6, places=7)

    def test_stability(self):
        for a,b in zip(softmax([1000,1001,999]),softmax([0,1,-1])): self.assertAlmostEqual(a,b)
        self.assertAlmostEqual(sum(softmax([-1000,0,1000])),1)
        self.assertEqual(loss([[1000,-1000,0],[0,0,0],[0,0,0]], [('A','B')]),2000)

    def test_boundaries(self):
        self.assertEqual(pairs([['A','B'],['C','A']]),[(0,1),(2,0)])
        self.assertEqual(pairs([[],['A'],['B','C']]),[(1,2)])

    def test_zero_rate_and_immutability(self):
        w=zeros(); seq=[list(TRAIN[0])]; old=copy.deepcopy((w,seq))
        result=step(w,seq,0); loss(w,seq); gradient(w,seq); predict(w,['A']); generate(w,['A'],8)
        self.assertEqual((w,seq),old); self.assertEqual(result,w)
        result[0][0]=99; self.assertEqual(w,zeros())

    def test_frozen_context_and_budget(self):
        w=step(zeros(),TRAIN); before=copy.deepcopy(w); context=['A']
        self.assertEqual(predict(w,['A','B']),predict(w,['C','B']))
        self.assertEqual(generate(w,context,0),context)
        self.assertEqual(len(generate(w,context,32)),33)
        self.assertEqual(generate(w,['A'],8),list('ABABABABA'))
        self.assertEqual(w,before); self.assertEqual(context,['A'])
        for v in [-1,33,True,1.5,'2',None]:
            with self.assertRaises(ValueError): generate(w,['A'],v)

    def test_invalid_data(self):
        for seq in [[],[[]],[['A']],[[True,'B']],[['D','A']],['AB'],None]:
            with self.assertRaises(ValueError): loss(zeros(),seq)
        for context in [[],[False],['Z'],'A']:
            with self.assertRaises(ValueError): predict(zeros(),context)

    def test_invalid_numbers_and_shapes(self):
        for v in [True, float('nan'), float('inf'),float('-inf'),'1',None,10**400]:
            w=zeros(); w[0][0]=v
            with self.assertRaises(ValueError): loss(w,TRAIN)
            with self.assertRaises(ValueError): step(zeros(),TRAIN,v)
        for w in [[],[[0,0,0]],[[0]*2]*3,None]:
            with self.assertRaises(ValueError): predict(w,['A'])
        with self.assertRaises(ValueError): step(zeros(),TRAIN,-.1)
        with self.assertRaises(ValueError): softmax([1e308,-1e308,0])
        self.assertEqual(softmax([1e308]*3),[1/3]*3)

if __name__=='__main__': unittest.main()

# Nine parameters: one real learning step

Python 3.9+; standard library only. No installation, API key, account, GPU, network or pretrained model. Extract `tiny-training-lab.zip`, enter `tiny-training`, then run:

```sh
python3 -B demo.py
python3 -B -m unittest -v
```

`-B` suppresses Python bytecode files. The demo computes in memory and prints JSON; it does not save weights. Read `core.py`, `fixtures.py` and `test_core.py` before execution. No user-provided code execution service exists on the website. This is actual numerical optimization of an original 3×3 logit table, not a Transformer, pretrained LLM, vendor evaluation or evidence of learning effectiveness.

## Contract
Vocabulary A/B/C; rows previous token, columns next token. One-token context. Full-batch mean cross-entropy with natural logarithm. Independent sequence boundaries are preserved. Training requires at least one transition; empty/singleton sequences contribute none. Unknown and bool tokens, nonfinite numbers, malformed tables, negative learning rates and invalid generation budgets fail with ValueError. Extremely large finite logits whose differences overflow also fail rather than return misleading values. No input is mutated. Step returns a new table; zero learning rate preserves values. Generation is deterministic greedy, tie order A/B/C, budget integer 0..32; no EOS, no promise of coherent language.

## Reproduce
TRAIN=A B A B A C yields 5 transitions. Zero table, learning rate 0.3. Expected mean loss 1.0986122886681098→1.0439803399807872; updated rows [-.06,.06,0], [.08,-.04,-.04], [0,0,0]. Floating-point near-zero residues are normal. The deliberately nonrepresentative A→A counterexample is never optimized; its loss rises to 1.159811928855196. This is not a representative held-out generalization test. For errors, restore original fixtures and zero table; do not edit expected answers to hide failures. A larger rate is not guaranteed to reduce loss.

Complete WORKSHEET-en.md before opening REFERENCE-en.md. Unit tests establish the implementation contract, not learner mastery. This lab has not undergone learner trials.

Mechanism reference: https://docs.pytorch.org/tutorials/beginner/basics/optimization_tutorial.html (loss and optimizer sections; editorial check 2026-11-01). All ABC data, calculations and code are original teaching material; PyTorch is not a dependency. See SOURCES.md for separate source dates.
