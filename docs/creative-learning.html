视频Agent：Underlord粗剪的差异审查与回滚

分类：agentic_application_feature；documentation-only / never-run

技术/工具节点：creative-underlord

学习目标与去重

既有FilmAgent/ViMax为研究编排，HKUDS VideoAgent与Kdenlive案例不覆盖商用会话剪辑的积分/回滚。

原创输入

只用原创/授权且无个人敏感信息的合成教学素材

账号与费用

Descript账户与计划；Free有限Underlord，付费能力/高阶模型不同；每次推理+工具均可能计费，同提示成本不固定。

许可与权利

服务条款而非开源模型许可；素材/人物同意/输出权利单独核验，不声称输出天然无版权风险。

权限/自动化边界

这是官方agentic应用功能，不是某单一模型。仅UI学习设计；本轮不调用API/MCP、不上传、不支付、不克隆声音、不发布。 恢复操作也是有副作用的项目修改，须先核对范围；本轮未执行Revert、Undo或Restore，也不保证无限历史保留。

历史/未知日期

帮助页当前Beta；v2历史公告日期未知，旧Labs开关与模型名不保留为现行操作。；精确首发日期unknown

文档操作路径（未执行）

  1. 打开已有授权项目的Underlord侧栏
  2. 给明确剪辑目标、禁止改动和长度约束
  3. 对照转录稿逐处检查编辑：当前session可在对应Underlord响应下Revert；刷新或关闭项目后改用File > Version history。先预览所选历史版本，核对整个项目全部compositions/files及协作者变更；确认恢复影响获准后才Restore Version。

原创练习验收（预期，不是实测）

  1. 先设计原始稿/剪后稿差异表，关键事实零删改
  2. 检查断句、画面跳切与字幕同步；不以工具自述判成功
  3. 记录提示前后Usage，达到自定预算即停；未经批准不发布
  4. 设计两个恢复分支：当前会话Revert，以及刷新/关闭后Version History；不得把checkpoint写成永久存在。
  5. Version History恢复影响全项目全部compositions/files，不只当前片段；先预览并审查协作者变化，再批准Restore。恢复后逐项核对，不能凭按钮点击或助手自述判成功；不承诺积分退回。

原创操作练习（未执行）

以下时长、数量、颜色和验收目标都是原创合成练习设定，不是厂商推荐或已经实现的产品结果。

用一份自写90秒科普讲解及对应自录素材设计45秒粗剪；三项核心事实标为不可删除，不采用声线克隆、生成配音或外部素材。

  1. 在纸面台账列原片段时间、事实句与允许删掉的重复语，保留未编辑副本。
  2. 写出仅压缩重复内容的受限请求及自定积分上限；待有授权再导入产品，不将本课当授权。
  3. 对每个拟删片段记录理由及可接受/拒绝决定；禁止因助手自述而跳过声音和画面复核。
  4. 设计当前session Revert与关闭后Version History两条恢复路径；后者先列全项目影响和协作者修改再审批。

预期交付物：原片/粗剪差异表；不变量检查清单；Usage前后记录模板；项目级恢复审批单

停止条件：不可删除事实被改动；预算不明或达到上限；历史版本含未批准的协作者变化；人物或媒体权利不明
